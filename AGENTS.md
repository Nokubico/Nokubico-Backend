# Instruções do projeto Nokubico Backend

## Idioma dos comentários

- Escrever todos os comentários de código e de documentação XML em português.
- Ao alterar código existente, traduzir os comentários manuais em inglês na área alterada.
- Preservar identificadores, comandos e marcadores técnicos gerados por ferramentas, como `<auto-generated />` e `<inheritdoc />`.

## Consulta obrigatória antes de escrever código

- Antes de criar ou alterar qualquer código, consultar sempre o servidor MCP do Microsoft Learn.
- Usar `microsoft_docs_search` para procurar documentação relevante para a alteração e `microsoft_docs_fetch` quando for necessário ler a página completa.
- Consultar `microsoft_code_sample_search` antes de criar exemplos ou implementações relacionados com tecnologias Microsoft.
- Basear a implementação na documentação consultada e nas convenções existentes do projeto.
- O servidor está configurado como `microsoft-learn`, com o endereço `https://learn.microsoft.com/api/mcp`.
- Se o servidor não estiver disponível, comunicar o impedimento antes de escrever código; uma pesquisa web não substitui esta consulta obrigatória ao MCP.
